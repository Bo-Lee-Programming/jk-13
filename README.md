## 玩法

独角兽从角尖编织一根承重的虹光索，用同一个物理机制完成三段试炼，让森林重新开花。移除了普通射击、二段跳与冲刺，将主题能力直接作为通关条件。

1. 接住高处树枝，缩短光索并摆荡，带着速度触及风铃；也可以断索后靠惯性飞向风铃。
2. 连接重石，将它向左牵引到黄金印记，保持光索绷紧以激活机关。单纯推石到位无效。
3. 绕到冲撞兽右侧，保持连接，将它的高速冲撞引向根墙；没有光索或速度不足时无法破墙。

完成后到达神树，有完整结局。这里的物理服务于摆荡、牵引和改变运动方向，而不是附加的场景装饰。

- A / D 或左右方向键：横向移动
- W / S 或上下方向键：在场景纵深中移动
- Space：跳跃；连接光索时释放，保留当前速度
- 按住 Shift：缩短光索
- E 或鼠标左键：连接当前试炼目标 / 释放
- 鼠标右键：释放光索
- Esc：暂停 / 继续；切出窗口自动暂停
- R：检查点重试；结局后重新开始
- M：静音

## 渲染与物理

`renderer3d.js` 提供实例化网格、透视投影、PCF 阴影、HDR 场景缓冲、四次辉光滤波和色调映射。不支持浮点色彩附件时使用普通色彩缓冲。树木、地形、苔藓纹理、植物、角色与音效均程序化生成，不下载素材。

`physics.js` 提供 120 Hz 固定步长积分、三维球体动量交换、质量与摩擦、地形/岩台碰撞、质量加权的单向绳长约束和 Verlet 绳索视觉模拟。同一个约束用于固定树枝、可移动重石和冲撞兽：松弛时不推物体，绷紧时约束分离速度，断索不凭空增加发射冲量。溪水波纹和远景光束属于视觉效果，没有流体动力学或参与介质的体积光模拟。

角色使用程序化关节动画和柔性尾部跟随；没有完整骨骼蒙皮资产。物理为针对当前关卡编写的轻量求解器，不是通用刚体引擎。

## 运行与验证

需要 Node.js 20+ 与支持 WebGL2 的桌面浏览器。

```powershell
npm install --no-package-lock
npm run dev
npm test
```

试玩地址：`http://127.0.0.1:1313/`。构建输出为 `dist/index.html` 与 `dist/game.zip`。构建器选择更小的标准 DEFLATE 压缩结果，验证解压内容一致，并在超过 13,312 字节时失败。

本轮验证的 ZIP 为 **13,081 字节**，余量 **231 字节**。压缩包只有顶层 `index.html`，所有网格、着色器与声音自包含。

测试覆盖动量交换、碰撞分离、20 秒绳索稳定性、松弛/绷紧约束、摆荡与无附加冲量释放、机关防绕过、重石恢复、冲撞破墙条件、暂停与死亡恢复，以及不使用传送的输入驱动全程通关。脚本最优路线约 13.1 秒，不代表首次游玩时长。浏览器检查涵盖启动、四足角色、实际虹光索画面与控制台；不等于跨设备性能保证。
